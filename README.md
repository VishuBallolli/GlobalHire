# GlobalHire

GlobalHire is an international job and recruitment platform.

## Project Goal

Build a platform where job seekers can find international
job opportunities and employers can post jobs and manage applicants.

## User Roles

1. Job Seeker
2. Employer
3. Admin

## Technologies

Frontend:
HTML, CSS, Bootstrap, JavaScript

Backend:
Node.js, Express.js

Database:
MySQL

Testing:
Postman

Additional:
Python
Git & GitHub
